Import children from a CSV file

Save your class list from Excel as CSV (Comma delimited). The first row must be the column names. Recognised columns: Last name, First name, Middle name (or one Name column as "Last, First Middle"), Sex, Grade, Section, LRN, Birthdate (yyyy-mm-dd), Parent, Phone, Email, Email 2, Alt name, Alt phone. Only the name is required. Children already in the list (same LRN, or same name) are skipped.

Moves children up to the next grade (same section name) and archives the ones who graduate or leave. Do this once, at the end of the school year.
